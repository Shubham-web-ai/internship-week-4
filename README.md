# Social Media Feed App

A full-stack social media application built using the MERN stack.

## Features
- User registration and login
- JWT-based authentication
- Create posts
- View the social media feed
- Like and unlike posts
- Add comments

## Tech Stack
- Frontend: React, CSS
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT and bcrypt

## Run Locally

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
Open another terminal:
```bash
cd frontend
npm install
npm run dev
```

Configure your environment variables in `backend/.env` before starting the backend. Never upload secrets to GitHub.
